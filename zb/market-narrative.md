## 一、定位与反共识

### 1.1 一句话定位

> **AI 好奇心引擎**是一款双界面 AI 应用：当家长无法实时陪伴时，帮助 10-14 岁高好奇孩子自主延续和深化兴趣，**不接管孩子的思考过程**，并通过家长端让家庭**事后**看到孩子的探索价值。

### 1.2 反共识主张（v0.3 升级）

**三条反共识主张**：

| # | 主张 | 对手在做什么 | 我们在做什么 |
|---|---|---|---|
| 1 | **KPI 是"孩子问出了什么新问题"，不是"学到了什么"** | AI 教育产品都在卷"孩子学到了什么" | 我们量化"问题数 + 跨学科延伸" |
| 2 | **双界面而非单界面**：因为教育的真正发生地不是屏幕前，而是饭桌上 | 单界面 = AI 替家长 / 替老师 | 双界面 = AI 翻译家长意图 → 孩子世界；翻译孩子好奇 → 家长端 |
| 3 | **AI 不当老师、不当朋友、当翻译器**——翻译家长的意图、翻译孩子的好奇 | Moxie 当情感陪伴（已倒闭）/ Khanmigo 当老师（仅 15% 学生用）| 我们做低维护、低侵入的"兴趣延续工具" |

### 1.3 与 v0.1 的差异（重要）

| 维度 | v0.1 | v0.3 |
|---|---|---|
| 核心叙事 | "亲子共同探索的媒介" | **"家长缺席时的兴趣延续"** |
| 家长角色 | 主动参与 + 共同探索 | **异步、低维护、事后回顾** |
| 价值承诺 | 改善亲子关系 | **不接管思考 + 让家庭事后看到价值** |

**为什么改变**：v0.4 决策 6（多维探索）+ ESA 家庭画像共同指向"家长深度参与时间稀缺"的真实场景。这是更可落地的产品定位。

## 二、目标市场（v0.3.1 重写）

### 2.1 一句话市场切片

> **首发市场（beachhead）**：亚利桑那凤凰城东谷（Chandler / Gilbert / Tempe）的 **self-directed learning 家庭**——选 Arizona 不是因为 ESA，是因为这里有**最密集的自定向教育社群 + 富裕家庭 + 我们能实际触达**
>
> **50 州扩展路径**：保留 5 个 4 星候选州（AZ / TX / FL / NC / CO）作为远景选项，**ESA 仅作为支付工具**，不作为选择 beachhead 的核心标准

### 2.2 核心修正：ESA 不在关键路径上（v0.4 反思）

**之前的错误认知**（v0.3 早期版本）：
> "Arizona ESA 政策最成熟 → 所以是好的 beachhead"

**修正后的认知**：
> ESA 是**支付工具**（降低 CAC），**不是**选择 beachhead 的标准。
> 关键路径是：**家长需求** → **孩子痛点** → **产品能解决** → **价格** → **怎么付**
> ESA 只在最后一步"怎么付"起作用，不在前面的需求侧起作用。

**家长的真实决策路径**：

```
1. 孩子有问题（痛点）→ 2. 我能解决吗？→ 3. 这产品能解决吗？
4. → 5. 多少钱？→ 6. 怎么付？

ESA 在第 6 步（"怎么付"），不是市场选择的核心
```

### 2.3 真正的 beachhead 选择标准（修正版）

按重要性排序：

| 标准 | 权重 | 评估方法 |
|---|---|---|
| **Self-directed / unschooling 社群密度** | 🔴 高 | Facebook 群组数 + Reddit + Meetup + ASDE 注册 |
| **富裕家庭比例 + 教育支出能力** | 🔴 高 | Census ACS + 行业估算 |
| **家长对 AI / 创新教育的接受度** | 🔴 高 | 反 AI 阻力评估 + 自定向社群活跃度 |
| **法规对 homeschool 友好度** | 🟡 中 | HSLDA 评估 |
| **ESA / 政府资金通道** | 🟡 中（支付工具，非核心）| EdChoice / State ESA Tracker |
| **已有 AI 教育产品渗透** | 🟢 低 | 间接估算 |

### 2.5 为什么是 Arizona（v0.3.1 修正论证）

**三大真实理由**（不再是 ESA 中心化）：

1. **Self-directed 社群密度可验证**
   - Arizona Families for Home Education（AFHE）
   - East Valley Athletic Coalition（EVAC）—— 几百个 homeschool 家庭参与的体育联盟
   - Arizona Association for Gifted and Talented（AAGT）
   - ASU Herberger Young Scholars Academy
   - 多个 FB 群组、co-op、meetup

2. **富裕家庭比例 + 教育支出能力**
   - Phoenix East Valley（Chandler / Gilbert / Tempe）是 AZ 富裕区
   - 中产 + 上中产家庭集中
   - ESA 资金 + 自费补充 = 已有付费习惯

3. **我们能实际触达**
   - 我们可在 EVAC / AFHE / AAGT 活动中现场演示
   - 可直接参加 Phoenix homeschool 展会
   - 地理集中 = 低 CAC

**ESA 现在只是"加分项"**：
- 未来可成为 ESA vendor 增加支付通道
- MVP 阶段不依赖 ESA
- ESA 资金可用性待深查（详见 `zb/ESA浅查结果.md`）

### 2.6 为什么不是"只 Arizona"

评委必然问：**"为什么不是 Texas / Florida / NC / Colorado？"**

**回应策略**：
- Arizona 是我们**验证最深的** beachhead，但**不是唯一选择**
- 50 州对比显示：4 个其他州（TX / FL / NC / CO）评分相同
- 我们的扩展路径：
  - **6-12 个月后**：扩展到 Florida / North Carolina（都已有 ESA）
  - **12-24 个月后**：扩展到 Texas / Colorado（自定向社群密度高）
- **不承诺**："Arizona 永远最优"——而是"我们先在这里验证，再扩展"

### 2.7 扩展路径图

```
v0.3（现在）: Arizona beachhead 验证
  ├─ MVP 12-18 个月: 1 个州 × 1 个城市群
  │
v0.4（6-12 个月后）:
  ├─ 加入 Florida ESA（如果 ESA 通道验证可行）
  ├─ 加入 North Carolina（universal choice 新机会）
  │
v0.5（12-24 个月后）:
  ├─ 加入 Texas（人口红利）
  ├─ 加入 Colorado（自定向社群密度高）
  │
v1.0（24+ 个月）:
  └─ 多州并行 + 全国扩展
```

### 2.8 ESA 知识要点（v0.4 浅查结论）

> 详细见 `zb/ESA知识库.md` 和 `zb/ESA浅查结果.md`

- **ESA = Empowerment Scholarship Account**（教育赋权储蓄账户）
- 亚利桑那州每孩每年约 **$7,000-$30,000**（按年级 + 特殊需求上浮）
- 流程：Service Provider Registration → 批准 → 家庭直接支付 vendor
- ✅ 流程清晰，可成为 vendor
- ⚠️ AI 软件订阅是否在标准批准清单**未明**——MVP 阶段假设不可行
- 🎯 **ESA 远景定位**：作为"降 CAC 工具"，不作为"市场选择标准"

### 2.9 年龄范围（v0.4 决策 2）

| 阶段 | 年龄 | 理由 |
|---|---|---|
| **MVP** | **10-14 岁** | 已付费意愿强 + 好奇心仍在 + 家长仍能影响 |
| 扩展期 | **6-14 岁** | 覆盖更大市场（含 6-9 岁"为什么"高峰） |
| 不做 | 0-6 / 15+ | 0-6 太早无产品交互能力；15+ 更接近青少年自主学习产品 |

### 2.10 多维切分方法（v0.4 决策 6）

**核心原则**：
- ⚠️ **不**预设"族裔不能用"或"行为才正确"
- ⚠️ **不**用族裔/阶层做硬筛选
- ✅ **同时采集** 12 维度数据，让数据告诉我们哪个维度切分后效果最好
- ✅ 严格遵守种族平等 / 法律合规

**12 维度矩阵**（Phase 3 访谈必标字段）：

| # | 维度 | 子分类 |

| 1 | 教育形态 | 全职 homeschool / 混合 / 公立 / 私立 / 线上 / unschooling |
| 2 | 孩子年龄 | 6-8 / 9-11 / 12-14 |
| 3 | 学习特征 | gifted / 2e / ADHD / 自闭谱系 / LD / 普通 |
| 4 | 家长教育理念 | acceleration / child-led / play-based / 宗教 / secular progressive / 升学导向 |
| 5 | 家庭结构 | 单亲 / 双职工 / 全职照护 / 多子女 / 跨文化双语 |
| 6 | 时间精力 | 有 / 无 / 部分 |
| 7 | AI 与屏幕态度 | 积极 / 谨慎 / 反对 |
| 8 | 隐私敏感度 | 高 / 中 / 低 |
| 9 | 地理 | 州 + 城乡 |
| 10 | 购买行为 | 谁决策 / 谁付费 / 订阅 / 一次性 |
| 11 | **族裔** | **记录但不作为筛选条件** |

- **全 Arizona ESA 家庭**
- **其他 ESA 州**（FL / WV / TN / MS / NC）

### 3.3 非目标人群（v0.3 必须明确）

**反向证据**（见 `zb/调研2.md` + `zb/调研2_执行错误记录/补充调研发现_v0.2.md`）：

| 非目标 | 原因 |

| 0-6 / 15+ 岁孩子 | 不在目标年龄 |

## 四、核心机制（v0.3 重写）

### 4.1 机制 1：Why-chain 深挖

| 要素 | 说明 |
|---|---|
| **输入** | 孩子问任意"为什么" |
| **AI 反应** | 不回答，反向追问 |
| **过程** | 难度自适应，一层一层挖下去 |
| **产出** | 每层生成可收藏的"探索卡片" |
| **累积** | 多层卡片组成"好奇心地图" |

**MVP 简化版**：why-chain 本身完整保留（这是核心），探索卡片可简化。

### 4.2 机制 2：去任务化翻译（核心差异化）

| 要素 | 说明 |
|---|---|
| **输入** | 家长在家长界面输入"观察 / 意图 / 价值观"（如"他最近在问恐龙"） |
| **AI 处理** | 把意图翻译成孩子世界里的"自然事件"（开放式谜题） |
| **输出** | 孩子看到的是"来自世界的有趣谜团"，不是"妈妈的作业" |
| **本质** | 家长有参与感，孩子无压迫感 |

**MVP 简化版**：
- 家长端简化输入（每日 1-2 分钟，不是持续配置）
- 翻译机制保留（这是核心）
- 复杂的"价值观解读"功能推迟到愿景期

### 4.3 机制 3：反向通道（愿景期）

| 要素 | 说明 |
|---|---|
| **输入** | 孩子在 AI 里挖到兴趣火花 |
| **AI 处理** | 识别兴趣火花的现实对应物 |
| **输出** | 推给家长一条"现实亲子建议"（如"周末带他去水族馆"） |
| **效果** | 把数字探索接到线下亲子关系 |

**MVP 简化版**：反向通道**不做**，仅保留"家长每日摘要"——让孩子看到孩子今天挖了什么，让家长事后回顾。

### 4.4 与 v0.1 差异

| 机制 | v0.1 | v0.3 |
|---|---|---|
| Why-chain | ✅ 完整 | ✅ 完整（MVP 保留） |
| 去任务化翻译 | ✅ 完整 | ⚠️ MVP 简化（低维护家长输入） |
| 反向通道 | ✅ 完整 | ⏸️ 推迟到愿景期 |
| 好奇心地图 | ✅ 完整 | ⏸️ MVP 简化（探索卡片即可） |

## 五、MVP vs 愿景（v0.3 新增）

### 5.1 MVP 范围（48 小时可交付）

| 模块 | MVP 内容 |
|---|---|
| 孩子界面 | why-chain 完整实现（3 层深挖） |
| 家长界面 | 每日摘要 + 简单输入框（1-2 分钟） |
| 去任务化翻译 | 保留核心机制，简化处理逻辑 |
| 好奇心地图 | 暂不做完整地图，仅做"今日探索卡片"列表 |
| 反向通道 | 不做 |
| 多维度用户分层 | 暂不做（产品 MVP） |
| ESA 通道 | 不做 |

**MVP 目标**：让评委看到"孩子问 why → AI 追问 3 层 → 家长收到摘要"的完整闭环。

### 5.2 愿景期（6-12 个月）

| 模块 | 愿景内容 |
|---|---|
| 完整双界面 | 家长端功能丰富（翻译 + 输入 + 回顾） |
| 完整去任务化翻译 | 深度理解家庭价值观 |
| 完整反向通道 | 线下亲子建议 + 现实联动 |
| 完整好奇心地图 | 长期兴趣图谱 + AI 学习曲线 |
| ESA 通道 | 申请成为 ESA vendor |
| 多州扩展 | FL / WV / TN / MS / NC |
| 50 州调研 | 验证更多州的市场适配 |

### 5.3 MVP 演示脚本（5 分钟）

```
1. 家长输入意图（30 秒）：
   演示者扮演家长，输入"孩子最近对恐龙着迷"

2. AI 翻译过程（30 秒）：
   屏幕显示 AI 思考 → 生成孩子界面的"恐龙小谜题"

3. 孩子收到线索（30 秒）：
   界面切换到孩子视角，看到"为什么有些恐龙的牙齿会替换多次？"

4. why-chain 深挖（2 分钟）：
   孩子点击 → AI 追问"你觉得为什么？" → 孩子回答 → AI 再追问 → 3 层展示

5. 今日探索卡片（1 分钟）：
   3 个探索卡片自动排版成孩子的"今日探索清单"

6. 家长端每日摘要（30 秒）：
   家长端收到推送"今日孩子探索了 3 个问题，主要方向：恐龙 + 自然规律"
```

## 六、商业模式（v0.3 重写）

### 6.1 双轨付费模型

| 轨道 | MVP 阶段 | 远景期 |
|---|---|---|
| **轨道 A：直订阅** | ✅ 立即启动 | 持续优化 |
| **轨道 B：ESA 通道** | ⏸️ 不做 | ✅ 申请 vendor |

**为什么双轨**：
- 直订阅 = 验证付费意愿 + 收集用户
- ESA 通道 = 政府背书 + 降低 CAC + 扩展市场

### 6.2 定价策略（v0.4 决策 12 用户保留）

**用户原话**："价格问题是待定选项，等所有调研结束后我亲自决定"

**当前方案**：
- MVP 阶段使用 **$19 / $29 双价格测试**作为数据采集
- **不预设最终价格**
- 等 Phase 3 真实用户数据后由用户决定

**OGB 文档参考**（`zb/former/`）：AI 好奇心引擎在头脑风暴中定价 $12-20/月
**v0.1 文档**：$25/月
**MVP 测试**：$19 / $29 两档（用户最终决策前）

### 6.3 单位经济学估算（待验证）

| 指标 | 估算 | 备注 |
|---|---|---|
| 月费 | $19 或 $29 | 用户决定 |
| 平均生命周期 | 12-18 个月 | 教育类订阅中位数 |
| LTV | $228-$522 | 取决于月费 |
| 允许 CAC | ≤ $100 | LTV/CAC ≥ 3 |
| 远景（ESA 报销） | $7K-$30K/年/孩 | ESA 通道启用后 |

### 6.4 ESA 浅查结论（v0.4）

**已验证**：
- ✅ Arizona ESA 流程清晰，可成为 vendor
- ✅ State ESA Tracker 是 50 州对比工具

**未明（需后续深查）**：
- ⚠️ AI 软件订阅是否在标准批准清单
- ⚠️ Service Provider Registration 的具体合规要求
- ⚠️ 各州规则差异

**维持判断**：MVP 不走 ESA，远景启用。

## 九、Why Now（v0.3 重写）

### 9.1 三个拐点

| 拐点 | 描述 |
|---|---|
| **技术拐点** | GPT-4+ 让 Socratic 对话引擎在低成本下可行（之前要靠人工专家） |

- JoySchooler 等真实竞品出现 → 抢市场窗口期
- AI 信任危机（Today.com AI 玩具事件）→ 越早建立合规越有先发优势
- ESA 政策可能变化 → 必须在政策窗口期内建立首批 vendor 关系

### 9.3 若不行动的代价

- **早 2 年**：AI 能力不够
- **晚 2 年**：JoySchooler 等竞品可能扩展到 10-14 岁
- **不行动**：错过 ESA 政策窗口期
