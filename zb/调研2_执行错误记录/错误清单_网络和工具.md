## 1. 网络连接错误（实际测试过）

### 1.1 主会话中测试的连接

在主会话中通过 `pwsh + Invoke-WebRequest` 实际测试了以下主机的 outbound 连接。**所有测试都失败**：

| # | 主机 | 协议 | 测试时间 | 结果 | 错误信息 |
|---|---|---|---|---|---|
| 1 | https://www.reddit.com | HTTPS | 本会话 | ❌ 失败 | "基础连接已经关闭: 接收时发生错误" |
| 2 | https://old.reddit.com | HTTPS | 本会话 | ❌ 失败 | "基础连接已经关闭: 接收时发生错误" |
| 3 | https://ar5iv.labs.arxiv.org | HTTPS | 本会话 | ❌ 失败 | "基础连接已经关闭: 接收时发生错误" |
| 4 | https://www.theguardian.com | HTTPS | 本会话 | ❌ 失败 | "基础连接已经关闭: 接收时发生错误" |
| 5 | https://duckduckgo.com | HTTPS | 本会话 | ❌ 失败 | "基础连接已经关闭: 接收时发生错误" |

**结论**：当前会话**完全没有 outbound 网络访问**——所有对外部站点的直接连接都立即失败。

### 1.2 实际执行的命令

```powershell
# 失败的命令 1 - 尝试 Reddit JSON API
$h = @{'User-Agent' = 'research-bot/1.0 (by hackathon team)'}
$r = Invoke-RestMethod -Uri 'https://www.reddit.com/r/homeschool/search.json?q=finished+curriculum&restrict_sr=on&limit=15&sort=relevance' -Headers $h -TimeoutSec 15
# 结果：ERROR: 基础连接已经关闭: 接收时发生错误。

# 失败的命令 2 - 尝试 ar5iv 论文
$h = @{'User-Agent' = 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) research'}
$r = Invoke-WebRequest -Uri 'https://ar5iv.labs.arxiv.org/html/2406.10461' -Headers $h -TimeoutSec 20 -UseBasicParsing
# 结果：ERROR: 基础连接已经关闭: 接收时发生错误。

# 失败的命令 3 - 系统性测试
$urls = @('https://www.reddit.com', 'https://old.reddit.com', 'https://ar5iv.labs.arxiv.org', 'https://www.theguardian.com', 'https://duckduckgo.com')
foreach ($u in $urls) {
    try {
        $r = Invoke-WebRequest -Uri $u -UseBasicParsing -TimeoutSec 8 -Method Head -ErrorAction Stop
        "$u -> $($r.StatusCode)"
    } catch {
        "$u -> FAIL: $($_.Exception.Message.Split([Environment]::NewLine)[0])"
    }
}
# 结果：所有 5 个主机都返回 "FAIL: 基础连接已经关闭"
```

### 1.3 这意味着什么

| 原本能做的事 | 实际能做吗 |
|---|---|
| 抓 Reddit JSON | ❌ 不能 |
| 下载 PDF | ❌ 不能 |
| 调用任何外部 API | ❌ 不能 |
| 浏览器抓页面正文 | ❌ 不能 |
| 用 `web_search` 找 URL | ✅ 能 |
| 用 `web_search` 看 snippet | ✅ 能 |

## 2. web_search 工具的能力边界（验证过）

### 2.1 能做的

通过本次调研确认，`web_search` 可以：
- ✅ 返回 URL
- ✅ 返回页面标题
- ✅ 返回搜索结果摘要（snippet，通常 1-3 句话）
- ✅ 找到讨论某个话题的 aggregator 文章
- ✅ 找到子链接清单（用于团队手动访问）

### 2.2 不能做的

`web_search` **不能**：
- ❌ 返回页面正文
- ❌ 返回 Reddit JSON 数据（即便主机可达）
- ❌ 返回 PDF body 内容
- ❌ 返回 paywall 后的内容
- ❌ 返回特定帖子的 selftext

### 2.3 实际遇到的限制案例

| 搜索词 | 返回 snippet 示例 | 限制 |
|---|---|---|
| "site:reddit.com/r/homeschool 'finished math' weeks" | 只有标题 + 1-2 句 snippet | snippet 不包含完整家长描述 |
| "arxiv 2510.24070 parent quotes" | snippet 提到"含家长直接引用"但**不能返回引用** | 必须人工访问 ar5iv |
| "Amazon Khanmigo review" | 返回产品页 URL 和 5-star 排名 | 不能看到具体评论 |

## 3. Subagent 的能力边界（明确失败）

### 3.1 Subagent 自报的能力

委托 subagent 抓 Reddit 数据后，subagent 报告：

> **No outbound network access.** Direct fetches fail at the TLS layer for *every* host, including `example.com`. `curl` reports `(35) schannel: AcquireCredentialsHandle failed: SEC_E_NO_CREDENTIALS`. This is a sandbox restriction on my delegated session that I cannot widen from inside it — approval prompts are disabled here, so I cannot escalate.
>
> My `web_search` tool returns only URLs and titles — no snippets or body extracts. So it can confirm that a page *exists* at a URL and what its headline says, but it cannot give me verbatim sentences, bylines, or table cells.

### 3.2 Subagent 没有的能力

- ❌ curl / wget
- ❌ browser / fetch
- ❌ outbound 网络访问
- ❌ 任何能访问页面正文的方式
- ✅ 只有 `web_search`（返回 URL + 标题）

### 3.3 Subagent 尝试的失败操作

| 操作 | 结果 |
|---|---|
| 14 次 `web_search` 跨 8 个痛点类别 | 没找到 1 条带 selftext 的 Reddit 帖子 |
| 尝试用 curl 抓 Reddit JSON | TLS 错误 |
| 尝试用 curl 抓 arxiv PDF | TLS 错误 |

### 3.4 Subagent 找到的（部分有用）

虽然没找到 selftext，subagent 找到了 **8 个 aggregator 文章**，作为 Reddit 讨论的二手引用：

| 痛点 | 文章 | 备注 |
|---|---|---|

| 2e 家庭 | TeamBlind - twice-exceptional kid | Reddit-adjacent |

## 6. Sandbox 限制的诚实记录

### 6.1 我们尝试过但失败的"补救"路径

| 路径 | 结果 |
|---|---|
| Subagent 委派 | ❌ 同样无网络 |
| pwsh Invoke-WebRequest | ❌ 基础连接关闭 |
| pwsh Invoke-RestMethod | ❌ 基础连接关闭 |
| pwsh Test-NetConnection | 未测试（直接推断会失败） |
| 多语言转译源（Russian / Spanish / Romanian 转载） | ✅ 部分有效——可验证 Atlantic 论点但拿不到正文 |
| Wayback Machine 存档 | 未测试，可能可用 |

### 6.2 我们**没有**尝试过的路径

- Wayback Machine 存档（如 https://web.archive.org/web/2026*/theatlantic.com/...）
- 学术论文的 ResearchGate / Google Scholar 镜像
- 论文作者的机构 repository
- Telegram 群组分享（部分 Reddit 内容会被搬运）

## 8. 缓解措施（团队可执行）

### 8.1 立即可做（无需新工具）

1. **人工浏览 aggregator 文章**：打开 [`补充调研发现_v0.2.md`](./补充调研发现_v0.2.md) 第 1 节列出的所有 URL，手动复制其中的真实家长引用
2. **下载 PDF**：用浏览器下载 NCES / NAGC / CSI Utah 报告，本地读 Table
3. **下载 Podcast**：用浏览器打开 "AI and Your Homeschool Podcast" 页面，听关键 episode

### 8.2 需要有网络访问的机器

1. **执行 §8.1 的命令**（在能访问外网的机器上）
2. **抓 Atlantic 文章正文**（gift link 或代理）
3. **抓 Chalkbeat 文章正文**（newsletter 订阅）

### 8.3 长期建议

- 比赛期间避免依赖任何"实时"内容抓取
- 把所有可访问的内容**预先下载到本地**
- 对不可访问的来源（paywall / 阻挡），在 pitch 中诚实标注"未能验证"
- **不编造**任何不能追溯到公开链接的内容
